# OPIc Pocket

학습 사이트: https://gywn000929-bot.github.io/opic-study/

밖에서도 소리 내지 않고 공부할 수 있는 OPIc 표현 학습 앱입니다. 20개 주제, 단어 400개·표현 300개·문장 300개를 제공합니다.

## 실행

`dist/index.html`을 브라우저에서 엽니다. CSS, 콘텐츠, JavaScript가 포함되어 설치나 외부 CDN 없이 동작합니다. 음성은 ‘발음 듣기’를 눌렀을 때만 재생되며, 기기의 영어 음성 지원에 따라 달라집니다.

현재 GitHub Pages는 `gh-pages` 브랜치의 루트에서 게시됩니다. `main`은 전체 소스와 테스트를 보관합니다. 수정 후에는 재생성한 `dist` 내용을 배포 브랜치에도 반영해야 합니다.

웹에서 사용하려면 `dist` 폴더 전체를 정적 호스팅에 올리세요. HTTPS에서 서비스 워커가 정상 설치되면 오프라인 재방문을 지원합니다. 아이폰은 Safari 공유 메뉴에서 홈 화면에 추가할 수 있습니다.

## 학습 기능

- 오늘의 10문항: 문장 조립, 문맥 빈칸 퀴즈, 한 줄 영작
- 표현 도서관: 1,000개 카드 검색, 주제·종류 필터, 영어 가리기, 즐겨찾기
- 문장 조립: 어구를 클릭해 참고 문장을 복원하고 피드백 확인
- 빈칸 퀴즈: 예문 속 강조 표현 또는 한글 뜻에 해당하는 표현 고르기
- 영작: 한글 뜻을 보고 직접 쓴 뒤 참고 문장과 비교 (자동 등급 평가 없음)
- 플래시카드: 자기평가에 따라 10분, 1일, 또는 점차 늘어나는 간격으로 복습
- 답변 뼈대: 묘사·경험·비교·롤플레이 질문에 맞춰 초안 작성
- 오답 복습, 주제별 진도, 최근 7일 학습, 연속 학습일
- 브라우저 기록 저장, JSON 백업과 복원, 다크 모드, 글자 크기 설정

완료는 표현을 충분히 이해했을 때 직접 표시하세요. 객관식·조립 정답 수와 카드 완료 수는 공식 OPIc 등급을 뜻하지 않습니다. 영작에는 같은 의미의 여러 정답이 가능합니다. 실제 말하기 능력은 별도 발화 연습으로 확인하세요.

## 기록

기록은 브라우저 localStorage에 저장됩니다. 계정 동기화는 없으며 브라우저 데이터 삭제나 기기 변경 전 설정에서 백업하세요. 파일 직접 열기와 웹 호스팅은 별도 저장 공간을 사용할 수 있습니다. 복습 날짜는 기기 시간 기준이고 연속 학습일은 현지 날짜 기준입니다.

## 개발

Node.js 18 이상에서 다음 명령으로 단일 HTML을 다시 만듭니다.

```sh
node build.js
node --check src/app.js
```

`src/content.json`은 학습 자료, `src/template.html`은 화면 구조, `src/style.css`는 스타일, `src/app.js`는 학습 동작입니다. `dist`의 manifest·서비스 워커·아이콘은 정적 호스팅용 파일입니다. 배포 내용을 바꾸면 `dist/sw.js`의 캐시 버전을 올려 주세요.

브라우저 통합 검사는 `tests/browser.cjs`에 있습니다. Playwright와 Chromium을 설치한 개발 환경에서 실행합니다. 테스트용 정적 서버는 스크립트가 직접 실행합니다.
