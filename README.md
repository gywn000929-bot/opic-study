# OPIc Pocket · IH+ 집중 훈련

학습 사이트: https://gywn000929-bot.github.io/opic-study/

이동 중에는 답변 흐름과 표현을 익히고, 이어폰을 사용할 때는 긴 답변을 듣는 OPIc 대비 학습 앱입니다. 표현 카드 1,000개를 유지하면서 경험·비교·묘사·롤플레이 중심의 12개 상황과 36개 심화 문항을 추가했습니다. 영작과 참고 문장 비교 화면은 제거했습니다.

## 하루 학습

기본 코스는 기존 10문항에서 **60문항**으로 확대했습니다.

| 목표 | 문맥 빈칸 | 문장 조립 | 답변 전략 | 듣기 이해 또는 답변 흐름 |
|---|---:|---:|---:|---:|
| 30문항 | 10 | 10 | 5 | 5 |
| 60문항 · 기본 | 20 | 20 | 10 | 10 |
| 90문항 · 집중 | 35 | 35 | 10 | 10 |

‘소리 없이’ 코스에서는 듣기 문항을 답변 흐름 복원으로 대체합니다. 같은 날 아직 학습하지 않은 문항과 미완료 문항을 우선 선택합니다. 문항 수만 채우기보다 질문의 요구, 시제, 원인·행동·결과의 연결을 확인하세요.

완료한 문항 다음부터 이어서 학습할 수 있습니다. 새 세트를 시작하면 기존 이어하기 세트를 바꿀지 확인합니다. 최근 학습량은 날짜별 서로 다른 카드·심화 문항 수로 집계하므로 같은 문항을 반복해도 중복 집계하지 않습니다.

## 훈련

- **답변 흐름:** 네 덩어리로 된 예시 답변의 시간·접속어·대명사를 단서로 순서를 복원
- **답변 전략:** 질문 요구에 맞는 전개 선택과 한국어 해설, 다른 상황에 적용하는 과제
- **듣기 이해:** 기기 TTS로 긴 예시 답변을 듣고 원인·행동·결과 파악; 속도 0.8/0.95/1.1배, 정지, 대본 학습 지원
- **표현 훈련:** 문장 조립·빈칸 퀴즈·플래시카드, 검색·주제 필터·영어 가리기·즐겨찾기
- **복습:** 오답 재도전과 자기평가에 따른 간격 반복
- **말하기:** 질문 듣기, 최대 3분 녹음, 재생, 다운로드, 자기점검 체크리스트

듣기는 질문 이해와 답변 전개를 익히는 보조 훈련입니다. 실제 OPIc에 별도 듣기 객관식 시험이 있다는 의미가 아닙니다. 예시 순서 외에도 자연스러운 답변 구성은 가능하며, 이 앱의 정답 수는 공식 말하기 등급을 평가하지 않습니다.

## 듣기와 녹음

듣기는 브라우저의 Web Speech API와 기기의 영어 음성을 사용합니다. 자동 재생하지 않으며 실제 재생 품질·오프라인 지원은 설치된 음성과 기기 환경에 따라 달라집니다. 소리가 나지 않거나 음성을 사용할 수 없으면 대본으로 학습할 수 있습니다.

녹음은 HTTPS와 마이크 권한이 필요합니다. 지원 브라우저의 MediaRecorder를 사용하며 외부 서버로 전송하지 않습니다. 페이지를 떠나거나 질문을 바꾸기 전에 파일을 다운로드하세요. 3분은 이 앱의 연습용 녹음 한도이지 공식 문항별 제한이 아닙니다.

사이트에는 AI 서버·자동 채점 기능이 연결되어 있지 않습니다. 말하기 화면에서 현재 질문에 맞는 연습 지시문을 복사해 사용 가능한 ChatGPT 음성 대화에서 연습할 수 있습니다. AI 피드백도 공식 등급을 확정하지 않습니다. 사이트 내부의 실시간 AI 피드백에는 별도의 서버와 API 연결이 필요하며, API 비밀키를 HTML이나 공개 저장소에 넣으면 안 됩니다.

## 기록과 실행

`dist/index.html`을 브라우저에서 열면 CSS·콘텐츠·JavaScript가 포함된 단일 파일로 학습할 수 있습니다. 웹에서 사용하려면 `dist` 전체를 정적 호스팅에 게시하세요. HTTPS에서 서비스 워커 설치가 완료되면 학습 화면의 오프라인 재방문을 지원합니다. 녹음·음성 재생은 환경에 따라 제한될 수 있습니다.

학습 기록은 브라우저 localStorage에 저장되며 계정 동기화는 없습니다. 설정에서 JSON 백업·복원, 글자 크기, 하루 목표를 변경할 수 있습니다. 다크 모드도 지원합니다. 기존 카드 진도·즐겨찾기·복습 기록을 유지합니다. 예전 영작 초안은 삭제하지 않고 백업에 남겨 두지만 학습 화면에서는 표시하지 않습니다. 이어하기 세트와 임시 녹음은 백업에 포함하지 않습니다.

## 개발과 게시

```sh
node build.js
node --check src/app.js
node tests/browser.cjs
```

Node.js 18 이상이 필요합니다. 브라우저 테스트에는 Playwright와 Chromium이 필요하며 테스트 스크립트가 로컬 서버를 시작합니다. 음성 API는 테스트에서 재생 호출과 상태 전환을 모의 검증하고, 녹음은 Chromium의 가상 마이크로 확인합니다. 실제 휴대폰의 음질이나 마이크 하드웨어까지 자동 검증하지는 않습니다.

- `src/content.json`: 기존 20개 주제·1,000개 표현
- `src/lessons.json`: 새로 작성한 12개 심화 상황, 답변, 해석, 선택지와 해설
- `src/template.html`, `src/style.css`, `src/app.js`: 화면과 학습 로직
- `dist/`: 단일 HTML, 설치 정보, 오프라인 캐시, 아이콘
- `main`: 소스·테스트 브랜치 / `gh-pages`: `dist` 내용만 게시하는 브랜치

수정 후 HTML을 다시 생성하고 서비스 워커 캐시 버전을 올린 뒤 `dist` 내용을 `gh-pages`에도 반영합니다.
